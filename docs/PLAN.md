# Технический план MVP

Главный критерий: «Убирает ли функция ручную работу оценщика?»
Приоритеты: 1) корректность расчётов, 2) удобство процесса, 3) автоматизация данных, 4) интерфейс.

## Исходное состояние

Репозиторий был пустым — проект создан с нуля.

## Важные решения

- **Демо-справочник.** Значения из образца (торг −5 %, первый этаж −6 %, материал ±5 %, мебель −4 % и т. п.)
  заведены как *демонстрационная* редакция с явной пометкой. Проверки предупреждают об её использовании.
  Для работы оценщик создаёт собственную редакцию (копию) с указанием источника или подключает
  лицензированный справочник (тип лицензии `licensed`).
- **Изменение корректировки** оценщиком требует обоснования — без него отчёт не формируется.
- **Даты и номера** хранятся в одном месте (задание/объект) и подставляются во все разделы отчёта;
  свободный текст проверяется на чужие кадастровые номера, даты оценки и площади.
- **Файлы** в MVP хранятся в PostgreSQL (до 10 МБ). Далее — S3-совместимое хранилище Timeweb.

## Что требует решения заказчика / договоров

- Источники данных: НСПД/Росреестр, ГИС ЖКХ, ФИАС/ГАР, ЦИАН/Авито/Домклик, картографический сервис —
  нужны договоры/ключи; архитектура адаптеров готова (`src/server/integrations`).
- Лицензированный справочник корректировок (например, отраслевые справочники) — по договору с правообладателем.
- Тексты стандартов СРО и методических материалов — с учётом прав на использование.

## Дальше (после MVP)

**Ближайшее**
- Оплата: Сбер Эквайринг (абстракция `PaymentProvider`, тарифы из конфигурации; поле `User.plan` уже есть).
- Хранилище файлов S3, сброс пароля по email, редактор шаблона отчёта.
- Android-приложение для RuStore как обёртка PWA (TWA / WebView) на том же API.

**Версия 2:** автоматический подбор аналогов через легальные источники, карты и инфраструктура
с расчётом расстояний, автоматический анализ рынка (Росстат, ЦБ РФ), другие типы недвижимости.

**Версия 3:** доходный и затратный подходы, коммерческая недвижимость, земля, дома, комнаты,
массовая оценка, электронная подпись, командный режим и роли организации.
