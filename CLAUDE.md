# Правила работы с репозиторием

- Основная ветка — `main`. Все изменения коммитить и пушить только в `main` (`git push origin main`); Timeweb разворачивает сайт из `main`.
- Перед началом работы: `git checkout main && git pull origin main` — рабочая копия после перезапуска окружения может оказаться на другой ветке.
- Не создавать pull request без явной просьбы.
- Отвечать пользователю на русском.
