# Файлы Росстата

Положите сюда файлы Росстата (CSV или XLSX) и запустите анализ структуры:

```bash
npm run rosstat:analyze
```

Анализ читает файлы потоково и сохраняет структуру (листы, число строк и столбцов, первые 40 строк,
строки с периодами) в таблицу `RosstatFile` и в `data/rosstat/analysis/`. По результату для каждого
файла составляется маппинг импорта (`scripts/rosstat/mappings/*.json`, формат — в `scripts/rosstat/import.mjs`),
после чего:

```bash
npm run rosstat:import -- --file data/rosstat/<файл> --mapping scripts/rosstat/mappings/<файл>.json
```

Значения хранятся в `RosstatValue` (показатель, регион, период, значение, файл-источник, дата актуальности),
повторный импорт обновляет значения без дублей. Данные Росстата — рыночный и территориальный контекст,
а не характеристики конкретного объекта.
