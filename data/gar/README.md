# ГАР (ФИАС)

Архив ГАР ФНС (`gar_YYYY-MM-DD.zip`, ~52 ГБ) **не добавляется в Git** — GitHub не принимает файлы больше 100 МБ.
Положите архив на диск сервера (например, в эту папку — она исключена из Git) и запустите потоковый импорт:

```bash
npm run gar:import -- --file data/gar/gar_2026-10-02.zip --regions 77,50   # выбранные регионы
npm run gar:import -- --file data/gar/gar_2026-10-02.zip --regions all     # все регионы
```

Архив не распаковывается и в память не загружается: записи ZIP64 читаются по одной, XML разбирается
SAX-парсером порциями, данные пишутся в PostgreSQL батчами по 5000 строк (upsert, повторный запуск безопасен).
В БД сохраняются только поля для поиска адресов: `GarAddrObj`, `GarHouse`, `GarHierarchy` и плоская
таблица `GarAddress` (регион, муниципальное образование, населённый пункт, улица, дом, полный и
нормализованный адрес, GUID). Журнал этапов — таблица `GarImport`.

После импорта в разделе «Объект» поле «Адрес» показывает подсказки из ГАР (`GET /api/address/search?q=…`).
